KEY DESIGN DECISIONS
═════════════════════════════════════════════════════════════════════════════════

1. Gatekeeper Pattern
   - Single entry point for all user requests
   - Sequential decision tree ensures cache is always checked first
   - Fails gracefully with error handling

2. Swarm Architecture
   - Dependency graph enables intelligent parallelization
   - Resource locking prevents hardware conflicts
   - Statistics tracking measures real performance gains

3. Watcher Implementation
   - Background loop doesn't block main flow
   - Pattern matching is lightweight (regex)
   - Integration with Neo4j enables knowledge reuse

4. Python 3.9+ Compatibility
   - asyncio throughout for consistency
   - Optional/Union typing for older Python versions
   - No breaking changes to existing tools
