KEY FEATURES
═══════════════════════════════════════════════════════════════════════════════

INTENT CLASSIFICATION
• Automatic categorization of user intents (9 types)
• Confidence scoring for routing decisions (0.5–0.95)
• Spanish language support (brillo, volumen, etc.)
• Dual-mode: Ollama + heuristic fallback
• Intent caching prevents re-classification

HYBRID ROUTING
• Local-first for speed (hardware, media, memory queries)
• Cloud-only for complex reasoning (code, research)
• Vision context enrichment for debugging workflows
• Automatic tool selection based on intent category

VISION AWARENESS
• Automatic screenshot capture on debugging queries
• OCR text extraction (optional via pytesseract)
• Smart caching to prevent redundant captures
• Region detection (Terminal/Editor/Full Screen)

RESILIENCE
• Ollama unavailable → Heuristic fallback (instant)
• pytesseract missing → OCR skipped, continues anyway
• Vision capture fails → Continue without context
• Always has fallback path to cloud APIs
